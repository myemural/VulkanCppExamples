# Grass Generation via Geometry Shader

**Code Name:** GrassGenerationGeometry

## Description

In this example, the geometry shader is used to generate grasses from randomly placed points on the ground, and these grasses are then appropriately illuminated in the fragment shader.

- Apply random placement and transformation techniques for grass generation
