# Hardware-Accelerated Ray Tracing

This section contains Vulkan examples that related to hardware-accelerated real-time ray tracing. It starts with the fundamentals of the ray tracing API (acceleration structures, ray tracing pipeline, shader binding table and ray queries) and continues with the real-time ray tracing techniques like shadows, reflections, global illumination, denoising and path tracing.
