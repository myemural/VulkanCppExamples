# Hardware-Accelerated Percentage Closer Filtering

**Code Name:** HardwarePercentageCloserFiltering

## Description

In this example, shadow mapping comparison and Percentage Closer Filtering (PCF) technique are implemented hardware-accelerated manner using a special sampler on the shader side.
