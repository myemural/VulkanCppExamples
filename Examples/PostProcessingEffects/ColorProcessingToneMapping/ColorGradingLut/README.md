# Color Grading with Using 3D LUT

**Code Name:** ColorGradingLut

## Description

This example demonstrates applying color grading using 3D LUT image that generated by a compute shader and applying color grading and tone mapping in a separate post-processing pass. Also compute shader can be set with several parameters.
